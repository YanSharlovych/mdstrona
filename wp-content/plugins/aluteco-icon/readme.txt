Visual ALUTECO SVG icon library with secure custom SVG uploads for Gutenberg.

== Installation ==

1. Open Plugins > Add New Plugin in WordPress.
2. Select Upload Plugin and choose aluteco-icon.zip.
3. Select Install Now and then Activate Plugin.
4. Open a page in the block editor and search for ALUTECO Icon.

== Usage ==

Insert the ALUTECO Icon block, then select Replace icon or Browse icon library.
Choose one of the bundled icons, search the visual catalogue, or upload an SVG
file up to 100 KB. Uploaded SVG markup is sanitized before it is displayed.
